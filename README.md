# Discord 人狼Bot

Discordの通話(VC)で遊ぶ人狼Botです。6人以上は「人狼ゲーム」、5人以下は「ワンナイト人狼」に自動で切り替わります。
決まったルールは `SPEC.md` にまとめています。

> **注意**: ルール部分とゲームの進行は、Discordのダミーを使って自動テストしています。
> ただし、本物のDiscordにつないだ動作はまだ確認できていません。最初は、テスト用のサーバーで試してください。

## ファイル

| ファイル | 内容 |
|---|---|
| `bot.py` | Botの入り口(コマンド、募集ロビー) |
| `session.py` | 1ゲーム分の進行(夜・昼・投票・終了) |
| `handlers.py` / `views.py` | ボタンやメニューの処理 |
| `game.py` / `roles.py` | ルール本体(Discordに依存しない) |
| `points.py` / `store.py` | ポイントの計算と保存(`jinro.db`) |
| `config.py` | 時間の設定(議論・夜・投票など)。数字を変えたいときはここ |
| `test_rules.py` | ルールとポイントのテスト(`python test_rules.py`) |

## セットアップ

### 1. Pythonを入れる
Python 3.10以上が必要です。https://www.python.org/ からインストールしてください。

### 2. Botを作る
1. https://discord.com/developers/applications で「New Application」を作る
2. 左メニューの「Bot」で、トークンをコピーする(**他人に見せない・公開しない**)
3. 同じ「Bot」の画面の **Privileged Gateway Intents** で、**Server Members Intent** をオンにする
4. 「OAuth2」→「URL Generator」で、SCOPES は `bot` と `applications.commands`、BOT PERMISSIONS は次にチェックする
   - View Channels / Send Messages / Embed Links
   - **Manage Channels**(天国・人狼の部屋の作成)
   - **Manage Roles**(VCで参加者以外を話せなくする)
   - **Mute Members**(自動ミュート)
5. 出てきたURLを開いて、Botをサーバーに招待する

### 3. 設定ファイルを作る
`.env.example` を `.env` という名前でコピーして、`DISCORD_TOKEN=` の後ろにトークンを貼ります。
`DISCORD_GUILD_ID=` にサーバーIDを入れると、コマンドがすぐ反映されます。

### 4. 起動する
```
pip install -r requirements.txt
python bot.py
```
「ログインしました」と出れば成功です。Botは、起動している間だけ動きます。

## 遊び方

1. 主催者が**ゲーム用のVCに入ってから**、テキストチャンネルで `/jinro create`
2. 参加者は、**同じVCに入って**「参加する」を押す(全員がVCに入っていないと開始できません)
3. 主催者が「ゲーム開始」 → 希望役職を選ぶ(30秒) → 役職が配られる
4. 役職は、「役職を確認」ボタンで、自分にだけ見えます(DMは使いません)
5. 夜は「夜の行動」から行動を選ぶ。昼は通話で話し合い、COは「CO一覧」のボタンで記録する
6. 投票は席順に1人ずつ。投票先を確定すると話せて、「意見終了」で票が公開されます

| コマンド | 内容 |
|---|---|
| `/jinro create` | 参加者の募集を始める |
| `/jinro roles 人狼2 占い師1 市民3` | 役職構成を手動で決める(主催者・開始前) |
| `/jinro stop` | ゲームを中止する(参戦費は返金) |
| `/pt` | 自分のポイント残高を見る |

## ポイント

- 初期ポイントは2000pt。参戦費は人狼ゲームが100pt、ワンナイトが10pt。残高が足りない人は免除で参加できます
- 配る報酬の合計は、払われた参戦費の95%まで。超えたら全員の報酬を同じ割合で減らします
- 詳しい数字は `SPEC.md` と `points.py` にあります
- ポイントは `jinro.db` に保存されます。消すとリセットされるので、バックアップを取ってください

## 注意点

- Botが再起動すると、進行中のゲームは消えます(参戦費は戻りません。`jinro.db` の残高は、ゲーム開始時に引かれた状態です)
- 自動ミュートは、**VCに入っている人**だけに効きます
- VCから抜けたまま、次の朝の発表までに戻らないと、突然死になります。夜が1回だけのゲーム(簡略化人狼・ワンナイト人狼)は、抜けた時点で突然死です。突然死した人は、抜けた夜より前の生存日数と役職ボーナスを受け取れます
- 「ゲームから抜ける」ボタンで途中退出すると、報酬なし・参戦費も返しません(SPEC.mdの「要確認」の項目)
- 狂人は、夜のアンケートで、一言(任意)も書けます。天国の夜の記録に載ります
